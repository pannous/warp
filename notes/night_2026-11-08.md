## Open questions for the morning
- as-text-not-cast (from save-picture-word, warp-structure-item): `save canvas as "x.png"` fails today: `as` is read as a cast, so only `save canvas as: "x.png"` works, and `{ save canvas as: "x" }` inside braces reads as a map. Recommendation: `as` before a text literal is never a cast (a text names no type), so it reads as the `as` parameter: `save canvas as "x.png"`, `save recording as "x.wav"` work without a colon, in braces too. Core: a small check where `as` is parsed. Alternatives: keep `as:`; or a different preposition (`save canvas to "x.png"`).
