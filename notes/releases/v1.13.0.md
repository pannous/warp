## warp 1.13.0: result types with `as`, GPU-first graphics, Windows, world feeds

- **Language**: a function head writes its result type `f(x) as T :=` (`f(x): T :=` still reads); the compiler and
  libraries are written so. Uniscript code point escapes `\:U+12C00`, `\:0x12C00` in either quote.
- **GPU**: a painted function over lists runs on the GPU, its list types inferred; the graphics libraries take the GPU
  path first and say a slow CPU fallback out loud. `compute_toys` is folded into `use shaders`.
- **Windows**: the first Windows release, `warp-v1.13.0-x86_64-pc-windows-gnu.zip`, installed by
  `scoop install https://github.com/pannous/warp/releases/latest/download/warp.json`; sources with `\r\n` line ends read
  as written.
- **World events**: `use feeds`, `use polymarket`, `use earthquakes` (Wikipedia's recent edits, prediction markets,
  quakes); `fetch` sends headers.
- **Playground**: 283 of 286 samples run in the page.

Everything else as in [1.12.1](https://github.com/pannous/warp/releases/tag/v1.12.1).
