## warp 1.5: warp from warp

warp is now written in warp and runs on its own native binary. The Rust compiler and the Rust `warp` binary are gone.

- **The compiler is warp.** `core/compiler.warp` compiles itself to `warp.wasm`. A seed compiler, published as a
  `seed-*` pre-release, starts the chain (`warp rebuild`). `warp self` runs `warp-self.wasm`, the compiler's build of
  itself.
- **The native warp.** `warp` is `core/native/warp.warp`, a primitive warp program built by `warp build native`
  (wasm2c and cc). It hosts `warp.wasm` through our own wasmtime C API, `libwarp_wasmtime`: wasmtime 50 with the
  copying collector and the GC setters. It runs `.warp` and `.wasm` files and code, `warp run|pure|self`, and
  `warp rebuild`. This native warp rebuilds `warp.wasm` from the seed and builds itself, with no Rust in the chain.
- **Primitive warp.** An `@primitive` file builds to plain MVP wasm with no GC and no runtime. It has C-layout
  structs, pointers and C calls (`getenv(name: pointer): handle from "c"`). `warp build native` turns it into a native
  executable.
- **Executables.** `warp build app.warp` writes `app`: the native driver carrying the program's module (~100 KB).
  C calls go through the module's `warp.c_functions`.
- **Linked modules.** `runtime.wasm` holds the runtime words, compiled once, and every compile links it. Standard
  modules (`use json`, `use sound`, …) ship prebuilt in `modules/`. A program declares their words and links them
  instead of compiling them again.
- **core/ reshuffled** into `parsing/`, `passes/`, `analysis/`, `emitter/`, `commands/` and `native/`.
- **Language.** Pattern clauses take lists and code apart (`len([h, t...]) := 1 + len(t)`). Enum cases take numbers
  and keep their enum. Class instances read fields by position (`P(2, 3)#1`). A type alias may name a union. Names
  are read from the expected type (`paint(Red)`). `play`, `beep` and friends work without `use sound`.

### Install
Each platform's tarball is one folder: `warp`, `libwarp_wasmtime`, the compilers and `lib/`. Unpack it anywhere and
link or put `warp` on your PATH, or `brew install pannous/tap/warp`, or install the `.deb` / `.rpm`.

### Known gaps
- 99 of 232 samples run on the native warp (`samples/`; 9 more need a window). 2.0 waits for most of them.
- Library host words (sound, graphics, gpu, web) are not all answered by the native warp yet.
- `warp build` needs Binaryen's `wasm-opt` (or `--trim=none`). Executables it builds find `libwarp_wasmtime`
  beside themselves, in `../lib`, or in the `lib` beside the warp that built them; a fully static option comes later.
- No Windows build and no PyPI wheel in this release.
