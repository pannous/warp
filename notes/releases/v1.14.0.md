## warp 1.14.0: patterns as types, sharper rules, GPU drawing, plots

- **Patterns**: `type X < Base = pattern` names a pattern; its holes are `$name`, typed `$name: Type`, the rest
  `$name...`. A class name before braces matches or builds that class, `Circle{r}`, and a class pattern may name some
  fields, by name in any order or by place, nested too: `Line(start: Point(x: 0, y))`. Braces before `=` take fields
  apart, `{start: Point{x, y}, end} = line`.
- **Rules**: a typed rule is written as the program is, `rule twice $x: int => thrice $x`; `until c { b }`, `x op= v`
  for every infix operator, `list of int` for `list<int>`, `map contacts to its name`.
- **Language**: `xs.each {…}` maps a block over the items; `c ? a : b`; a blank before `#` and none after is the
  count; an operator ending its line continues only onto a deeper-indented line; `date(2024, 2, 29)` builds a date
  and a date outside the calendar is refused; a recursive lambda, `fact = n => … fact(n - 1)`, runs; an expression
  passed to a block parameter is its block, `twice(n += 1)`.
- **Graphics and sound**: `use draw` draws its shapes on the GPU; `paint(shader)` shades at the window's own pixels;
  `plot(f, from, to)` draws a function's graph; `pga_draw` draws and answers geometry questions (samples/geometry);
  USDCraft objects fall as rigid bodies; `pause` is a rest, `play(pause, 1s)`.
- **Playground**: ⌘ . and Ctrl C stop a run; 292 of 295 samples run in the page; 15910 of 16340 test lines pass.
- **wap**: the next compiler, wap, is being built beside this one (notes/wap.md): it reads, binds, types and emits
  functions, records, lists, texts and rules through its own stages; `.wap` sources are warp code to the native warp.
  This is one of the last releases of the current compiler (core/).

Everything else as in [1.13.0](https://github.com/pannous/warp/releases/tag/v1.13.0).
