## warp 1.9.0: paths, checked types and faster libraries

- **Paths**: an unquoted path is a path: `write ./shopping.txt "milk"`, `read ./shopping.txt`, `~/notes.txt`,
  `/etc/hosts`. Samples, the guide and the tour write file names this way.
- **Types**:
  - A parameter or variable typed by a class is checked: `f(d: Length) := d; f(5s)` is refused with "f takes a
    Length, not 5s (a Time)"; a standalone class is checked by its fields. A bare number takes the unit's conversion:
    `f(5)` is 5m.
  - Time types hold and check their values: `d: date? = ø`, `x: duration = 2 hours`, `class car { year: date? }`;
    `x is date`, `x is instant`.
  - `ps: [P]` is a list of P: `ps#2.a` reads the field; `xs: [int]` adds numbers, not texts.
- **Functions**:
  - `f := x => x*2` and `h := square & square` define functions.
  - A parameter that is called or run is declared so: `apply(f: function, x) := f(x)`, `repeats(n, body: block)`;
    calling an untyped one is refused with that fix-it.
  - A pipe binds weaker than a call without parentheses: `square 3 |> text` is `text(square 3)`.
  - A global named like one of the program's functions is refused, naming each place it is declared.
- **Operators**: an operator is chosen by the types of both operands, also reversed (`2 * v` with `*(k: number, v: V)`
  in V); a class answers `≈` and `~` by its `approximately(o)` and `similar(o)`: `(1 ± 0.1) ≈ 1.05`.
- **Libraries**: a ring buffer, a disjoint set; `window(xs, 0)` is refused instead of giving empty windows.
- **Sound**: `play` is the one word that plays; `chord` makes a chord to play.
- **GPU**: a shader may call functions brought in by `use`; the Gaussian splatting sample opens on a honeybee.
- **Speed**: a library's definitions with a result type stay in the library until called: `use sound; 1` compiles in
  18.3 instead of 51.6 G instructions, `use units; 1` in 13.5 instead of 28.4.
- **Packages**: the PyPI wheel's install check finds `warp` where Debian's pip puts it.

Everything else as in [1.8.0](https://github.com/pannous/warp/releases/tag/v1.8.0).
