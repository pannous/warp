## warp 1.6.1

A catch-up release: its native warp knows the host words today's compilers import, so a fresh install (and the cloud
suite's bootstrap) can build main again; v1.6.0's native warp stopped in the seed step.

- **Tasks**: `go { … }` is a cooperative task that starts when main yields (a `sleep`, an `await`, a channel receive, or
  main's end); `go for x in xs { … }` runs each iteration as a task; `shared n = 0` is one value every task sees.
- **Defaults**: `x default y` and `x ?? y` give a fallback for a failing or `ø` value; a bare `try` handles an error,
  `r = try f(0)`.
- **Loops and calls**: `for i in 3` counts 1 to 3; `f ()` calls `f` with no arguments, as `f()` does.
- **Spacing warnings**: `a *b` computes with a warning, `1 +1` warns that it is two items; both suggest the fix.
- **map**: `map floor [1.5 2.5]` and `map count xs` use the library word again; `map(floor, xs)` maps like `map(xs, floor)`.
- **Units**: tolerances `5m ± 1cm`; a unit-typed field prints in its unit, `x: km = 1500m` shows `1.5km`.
- **Lazy ranges**: `1..10^12` holds only its two ends, so `count`, `#`, `sum` and indexing answer at once.
- **Stored tables** are written through: `add` inserts a row and sets the instance's id, a field write updates the row,
  `transaction { … }` commits or rolls back as a whole.
- **Playground**: the browser playground runs the self-hosted compiler, with `use sqlite3` and `use python`; its
  compiler loads in one request instead of 85.
- **Sugar** moved from lib/sugar/ into the compiler (extensions/sugar/).
- Fixes across overload resolution (arity overloads inside one class), error handling, MP3 length, type aliases of
  function types, and more.

Everything else as in [1.6.0](https://github.com/pannous/warp/releases/tag/v1.6.0).
