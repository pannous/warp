## warp 1.12.0: loud slow paths, PNG reading, URL reads and deeper recursion

- **Language**:
  - A loop variable and a `let` are the function's own, never a global of that name; a match arm's pattern names are its own.
  - A list reads the plural of its items' field: `people.names`, `names of people`.
  - `7//2` and `x//=3` warn that `//` starts a comment and name `/!` for floor division.
  - A sum of more than 32 unlike exact terms is the float's, so a loop adding roots runs in a second instead of hours.
  - A missing key names the entry ø at run time instead of trapping; a spaced call of a library word picks its definition by arity as a round one does.
  - A pronoun in a spaced definition head is dropped (`twice it := it * 2`); `sq 2 + 1 == 9 and yes` is refused as reading two ways.
  - A program recurses a million calls deep again (wasmtime's stack limit 240 MB, the program on a thread of 256 MB).
  - `help(x)` on its own line prints, as Python's help.
- **Slow paths are loud**: `slow(reason, fix)` (`use os`) says a library's slow fallback once per reason on standard
  error, and `warp --strict` refuses it; the GPU storage uploads that walk numbers call it.
- **Libraries**:
  - `read` of a URL gives its text over HTTP, natively and in the page; `image(url)` loads a picture.
  - `image` reads PNGs in plain warp (gray, RGB, palette, alpha, 1 to 16 bits, interlaced).
  - A MIDI file is a `MidiFile`: `save(MidiFile(notes), path)` writes it and `midi_file(path)` reads it.
- **Graphics and pages**: dark mode swaps paper and ink wherever a picture is shaded (a run with no window follows no
  theme); Escape closes the window of an `on frame` program while debugging; a go task's sounds sound beside main's.

Everything else as in [1.11.0](https://github.com/pannous/warp/releases/tag/v1.11.0).
