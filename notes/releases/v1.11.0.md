## warp 1.11.0: a language server, sliders, one play and nullish defaults

- **Tooling**:
  - `warp lsp` is the language server for editors (Sublime's LSP package, VS Code): go to definition, hover and the
    compiler's refusal of an open file as a diagnostic.
  - PyPI: `pip install warp-language` also brings `warp_language.node`, pure Python that reads and writes warp data as
    Python values (`parse` / `serialize`, no binary needed).
- **Language**:
  - `x ?? y` replaces only ø, a raise in x stays one; `default`, `otherwise`, `failing`, `except` and `rescue` give y on
    ø or a raise.
  - `round(x, decimals: n)` and `round(x, 2)`; `delete(path)` removes a file; `remove alarm` removes a listener.
  - A function named like a used module's word replaces it with a warning (`use sound; play(x) := …`).
  - `x as html` is the page's own HTML; ints past 64 bits cross to and from Python by their digits.
  - `warp fast <program>` runs untyped whole numbers as wrapping i64.
- **Sound**: `play` is the one playing word (`play(Pattern("…"), bar 1)`, `play ./song.mp3`) and gives a Sound handle;
  `use music` and `use audio` are `use sound`.
- **Playground and pages**: `slider(-2 to 2)` is a UI value with a control; a key pressed in an element is its
  `on enter` / `on escape` event; Run on unchanged code starts at once.
- **Graphics**: EZ Tree forests with meshlet culling on the GPU, passes shaded at the window size.
- **Compiler**: ECMAScript's Math, JSON and Reflect are declared like the web's, so `Math.nonsense(2)` is refused at
  compile time; primitive programs have fixed arrays (`i64[8]`) and mutable globals.

Everything else as in [1.10.0](https://github.com/pannous/warp/releases/tag/v1.10.0).
