## warp 1.8.0 🎉 every sample runs

Every sample runs in the browser playground: 254 of 254 print what the native warp prints, draw their window or
serve. Natively every sample runs as planned too: a window, a server or a sample that fails on purpose counts as a
pass, and the one red line left is a server sample that dies under a parallel sweep.

- **Playground**: `~` is the page's own file store, a page run reads relative paths beside its program, files reached
  through folder links are served, and `use "•/…"` no longer climbs folders forever. A stale page reloads itself once
  when the server has a newer build. A worker that stops says so and restarts.
- **iPad and Safari**: `local["name"] = "Ada"` and the other storage words link the prebuilt storage module, about 1 s a
  run where Safari's worker ran out of stack before.
- **Language**:
  - `x is Key(h, …)` and `r is {status: s}` bind their names, as `match` does; a failed match alternative keeps no
    bindings.
  - Operators carry English names (`equal`, `less_or_equal`, `default` for `??` …), and `Op.Other` covers any other
    operator; a class defines `==(o) := …` or `equal(o) := …`.
  - `all xs in t`, `any xs in t`.
  - `def two: 1+1` is the function `two()`; `f(a, b: 0)` is refused with "a default is written b = 0".
  - A control keyword is no variable name (`until = 3` is refused); `time 6` is a 6 s duration, `time { … }` times a
    block.
  - `fields(E)` of an empty class, `x.word` reading a field named like a word (`{once: {a: 1}}.once.a`).
  - `⌈2.1⌉` without `use math`.
- **Units and numbers**: `3m as pixels`, `2 as length`; exact sums; `now()` is a time.
- **GPU**: Gaussian splatting with WebGPU (instanced quads, the projection on the GPU at 43 ms a frame);
  `gpu_render` natively; `gpu_compute` changes the lists it is given in place.
- **FFI**: a boxed int reaches a C i64 parameter exactly; a C text argument is no longer overwritten by an inner host
  call; a program's own C declaration may share its line with other statements.
- **Native**: `run([…])` gives `{status, out, err}`; `env` reads what `set_env` set; `eprint` writes to stderr; a trap
  names itself instead of a bare 0; the `uname` buffer that overwrote the heap and killed servers is fixed; a crash
  prints its signal.
- **Builds**: `warp rebuild` also builds the native warp (`warp rebuild pure`: the compilers alone); a module's
  prebuilt file links only while the module is listed; a trapping module compile is refused by name.
- **Compile speed**: the passes that scaled with the library find things through maps (2000 lines 99.5 → 81.9 G
  instructions); a linked class gives a program only the methods it calls (`use sound; 1` 26.2 → 17.1 G).

Everything else as in [1.7.0](https://github.com/pannous/warp/releases/tag/v1.7.0).
