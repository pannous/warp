## warp 1.10.0: subtypes, complex numbers and a leaner compiler

- **Types**:
  - `type A < T` declares a subtype: it takes everything of T (`is` tests, T-typed parameters and fields, `A(value)`)
    and may define its own operators and format; `type A = T` is a plain alias. `type Age < duration; 3 years is Age`,
    `type Name < text` prints and joins as text, `class P { age: Age }; P(3)`.
  - Aliases of composite types: `type Code = list of int`, `int[]` or `[int]`.
  - A type alias is called as its type: `Age(3)`, `double(3)`.
- **Complex numbers**: `ⅈ` is the imaginary unit and brings `lib/complex` by itself; Complex takes `^`, so
  `z = z² + c` works, also in shaders (`c = -0.8 + 0.156ⅈ`). Complex numbers work in the playground and under
  `warp build`.
- **Time**: `zoned(now, "UTC")`, `T + 2 seconds`, `zoned(…) + 24 hours` work with the time library linked; `T + 3` is
  refused with "a time takes + or - a duration"; `today()` has a `weekday`.
- **Operators and functions**:
  - `÷` is floor division (`/!` its alias).
  - `greater(a: list, b: int) := all a > b` defines `>`.
  - A character equals its code point: `"ab".codepoints#1 == 'a'`.
  - `x.w` is x's own field w, else `w(x)`.
  - A function whose parameters all have defaults is called by its bare name (`use shell; ls`).
  - Calling an undefined word says so with suggestions: `no function from_hex; fix: did you mean is_hex_digit, …`.
- **Markup**: markup is only what stands inside `html{…}` or a function typed html; a data key named like a tag
  (`{b: 1}`, `{i: 1}`) stays data.
- **Console**: Alt+←/→ jump a word back and on; Home/End, Delete and Alt+Backspace edit as in macOS Terminal; typed
  lines stay in `~/.warp_history`.
- **Playground**: C library and zlib calls (`write`, `calloc`, `use z`); `eval` and `parse_code` work again; a shader
  error names its line and column; the bug button has a "quick" choice.
- **Compiler**: no library is baked into the compiler any more (core takes what it uses); the first run after an
  install no longer recompiles the driver (0.47 → 0.13 s for hello).

Everything else as in [1.9.0](https://github.com/pannous/warp/releases/tag/v1.9.0).
