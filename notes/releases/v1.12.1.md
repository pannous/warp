## warp 1.12.1: a console that starts at once

- **Console**: the install ships the console's machine code, so a first `warp` console starts in 0.06 s instead of 8 s;
  a first `warp fuel` run of a program builds no machine code either.
- **Language**: a call picks its overload by the kinds of typed parameters; a definition whose body assigns `it` keeps it
  as its own local.
- **Libraries**: a host module's run-time error is said as a sentence; `show(image)` works again on macOS.

Everything else as in [1.12.0](https://github.com/pannous/warp/releases/tag/v1.12.0).
