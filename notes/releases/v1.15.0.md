## warp 1.15.0: optionals that unwrap, Euclidean remainders, programs from a URL, a faster compile cache

- **Language**: `x!` unwraps whatever a program declares optional, a function's result and a parameter alike, and
  raises when it is missing; `list<int>?` and `map<text, int>` are the types they spell; a class field's default may
  name a value the program assigns; `w = f(x) ?? continue` keeps `f(x)`; `x is not empty` tests emptiness.
- **Numbers**: a yes or no beside a number compares as 1 or 0, `1 < 2 == 1`; a text times yes or no is refused like
  a text times any other non-number.
- **Texts**: a regex reads its pattern and subject as UTF-8, so `.` is one character, `é` or `😀` too.
- **CLI**: `warp <url>` fetches a program and runs it; `warp --no-cache` compiles cold and keeps nothing; the compile
  cache keeps one module per program file and replaces it when the compiler or lib/ changes; `warp build` names its
  files by the program without its last ending and never writes over the program itself.
- **Web and graphics**: the native warp answers `net.post` by curl, its headers as lines as `net.get`'s; a window's
  frames let the GPU free what each released (samples/gpu/rings no longer grows); the console defines a function by
  the normal rules again, another signature an overload.
- **Samples** now live in their own repository, pannous/samples, linked into every tree at samples/; 299 of 304 run
  natively, 279 of 300 in the page; 15947 of 16374 test lines pass.
- **wap**: the next compiler moved to its own repository, pannous/wap; this compiler (core/) gets fixes and few new
  forms.

Everything else as in [1.14.0](https://github.com/pannous/warp/releases/tag/v1.14.0).
