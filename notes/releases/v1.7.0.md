## warp 1.7.0 🎉 zero bake

The compiler carries no library any more: every program links the modules it uses, the prelude included, when it
loads. warp.wasm went from 5.05 MB to 2.11 MB, and the compiler compiles itself about 40% faster than two days ago.

- **Load-time linking**: each standard module is its own prebuilt wasm (modules/*.wasm, 89 of them) with a
  `warp.signature` section; a program imports only the words it reaches and links them when it starts, in native warp
  and in the browser playground alike. `warp signature units` prints a module's signature.
- **The prelude links like any module** (modules/prelude.wasm, 222 words, 183 KB): no prelude word is compiled from
  source in a program any more.
- **Open words**: a module's word another module extends (units' durations reaching lib/time's `Instant + 2 seconds`)
  goes through a slot the program fills at start; a program's own same-named helper never reaches into a module.
- **Size**: warp.wasm 5.05 MB → 2.11 MB; the only library data left inside is the sugar rules (and three small data
  files).
- **Speed**, instructions retired:
  - hello: 5.2 G → 3.07 G
  - `use units`: 17.8 G → ~11.6 G
  - the self compile: 2.58 T → 1.45 T (typed nodes −9%, the lambdas index −5%, code_only kept per source −12.5%,
    map lookups −8%, typed list items −6%)
- **Hashing**: module sources are hashed with the host's sha256 (no length limit for host text arguments).
- **Lazy host libraries**: a host word's library is opened at its first call, so hello opens none.
- **Constants**: `let`/`const` names can't be assigned again (`fix: var k`); `pi = 4` is refused, "pi is a constant".
- **Class descriptors**: an instance carries its class (`x is Foo` and `type(x)()` from it); closures carry their own
  function reference.

Known, fixed forward: `use sound` programs fail with "no field address" since open words (card
linked-cross-module-overloads); some browser tours (canvas `show`, markup `bind:`/`transition:`) are on cards.

Everything else as in [1.6.1](https://github.com/pannous/warp/releases/tag/v1.6.1).
