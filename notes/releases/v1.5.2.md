## warp 1.5.2

- **Read-only installs.** The native warp runs from a lib/ it can't write: the `.deb` and `.rpm` (`/usr/lib/warp`)
  work now. Machine code it can't keep beside lib/ goes to the user's cache folder.
- **Implicit standard uses** no longer take a field name (`{g: 5}`) or a loop variable (`for c in …`) for a standard
  module's word: `q = {g: 5}; q.g` is 5 again.
- A type word's conversion takes its value before a comparison (`int 3.7 == 3`).
- 120 of 232 samples run on the native warp (105 in 1.5.1; 9 more need a window).

Everything else as in [1.5.1](https://github.com/pannous/warp/releases/tag/v1.5.1).
