## 🤖 Assistant

Yes, two options:

**1. Simple - Use `#[ignore]` with reasons (no extra code)**
```rust
#[test]
#[ignore = "todo"]
fn test_foo() { }

#[test] 
#[ignore = "next"]
fn test_bar() { }
```
Then filter: `cargo test -- --ignored` runs all ignored tests.

**2. Custom attributes - Requires a proc-macro crate**

Create `tests/macros/` or a separate crate:

```rust
// In a proc-macro crate
use proc_macro::TokenStream;

#[proc_macro_attribute]
pub fn todo(_attr: TokenStream, item: TokenStream) -> TokenStream {
    let item_str = item.to_string();
    format!("#[test]\n#[ignore = \"todo\"]\n{}", item_str).parse().unwrap()
}

#[proc_macro_attribute]
pub fn next(_attr: TokenStream, item: TokenStream) -> TokenStream {
    let item_str = item.to_string();
    format!("#[test]\n#[ignore = \"next\"]\n{}", item_str).parse().unwrap()
}
```

Then use:
```rust
#[todo]
fn test_something() { }
```
