## 🤖 Assistant

All automatic via Cargo.toml. Just run `cargo build --release` and you get the 3.5MB binary.

The settings in `[profile.release]`:
- `opt-level = "z"` → compiler optimizes for size
- `lto = true` → link-time optimization removes dead code
- `codegen-units = 1` → better cross-module optimization
- `panic = "abort"` → removes unwinding machinery
- `strip = true` → removes symbols automatically

Plus the wasmtime feature trimming removes unused runtime components at compile time.

No manual `strip`, UPX, or post-processing needed.
