Done! The `wasm_object!` macro now works with explicit type annotations:

```rust
// Before: requires separate struct definition and instance
wasm_struct! { Person { name: String, age: i64 } }
let alice = Person::new("Alice", 30);

// After: one-liner creates both!
let alice = wasm_object! { Person { name: String = "Alice", age: i64 = 30 } };
```

**Why full type inference isn't possible:** Rust's declarative macros (`macro_rules!`) are purely syntactic - they can't inspect the type of a literal like `30` at compile time. That requires:
- Procedural macros (separate crate)
- Or const generics with unstable features

The explicit type annotation syntax `field: Type = value` is still a significant improvement over the two-step approach and remains unambiguous.
