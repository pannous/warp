Fixed. The issue was in `PartialEq` for `Meta` nodes at `src/node.rs:1152-1158`.

**Problem**: When comparing `Meta(a) == Meta(b)`, it was comparing `a` (unwrapped) with `Meta(b)` (still wrapped). Since `Symbol` doesn't match `Meta`, the comparison failed even when the inner values were identical.

**Fix**: Now both sides are unwrapped before comparison:
```rust
Meta { node, .. } => {
    let other_unwrapped = match other {
        Meta { node: other_node, .. } => other_node.as_ref(),
        _ => other,
    };
    node.as_ref().eq(other_unwrapped)
}
```

This makes `parse("a b c") == parse("a, b, c")` work correctly, since the only difference is position metadata (which should be ignored) and separator type (already ignored by List comparison).
