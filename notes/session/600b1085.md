## 🤖 Assistant

Fixed. The parser was hanging due to three related bugs:

**Bug 1: `//` treated as division**
When the parser saw `a{} // comment`, it treated the first `/` as a division operator and tried to parse `// comment` as `/ / comment`, creating an infinite cascade.

**Fix:** Added `if c2 != '/'` guard in `peek_operator()` so `//` is not matched as division:
```rust
'/' if c2 != '/' => Some((Op::Div, 1)),
```

**Bug 2: Infinite loop on end-of-input** 
The early `at_end` check only compared against the close character, not `\0`. When errors consumed closing brackets, the loop ran forever.

**Fix:** Added `|| ch == '\0'` to the check:
```rust
Some(c) => ch == c || ch == '\0',
```

**Bug 3: Closing brackets consumed as errors**
`parse_atom()` consumed `}`, `)`, `]` as "unexpected characters" instead of returning `Empty` for the caller to handle.

**Fix:** Added them to the terminator list:
```rust
';' | '>' | '}' | ')' | ']' => Empty,
```
