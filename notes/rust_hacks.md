# Rust's name-keyed hacks and the general rules warp uses instead

Survey (card rust-hacks-survey, 2026-10-22, main 6bfc3c1deb) of src/lowering, src/analyzer, src/wasm_emitter, src/law and
core/*.warp for special cases keyed on a word: word lists, per-word templates, closed forms, fast paths. The
Rust stays as it is (frozen legacy, notes/agents/common.md); each hack gets the banner
`// ⚠ WARP DOES THIS DIFFERENTLY: <what> → <lib file>` once warp has the general rule. Vocabulary that only names
keywords (`for`, `in`, `break`/`continue`/`next`, prepositions, articles) is no hack and is left out.

Ranked by gain: warp copies first (a hack copied into core is twice the debt and blocks the self-hosted
compiler), then by how many words and sites one rule replaces. "Lines" is the size of the tables and the code keyed on
them, roughly.

## Pattern

Most hacks are one of three things a word's prelude line could already say: its result (rows 1, 6, 12), its effect
on its arguments (row 3), its runtime target and arity (rows 4, 5). builtin_signatures.warp reads the lines once;
every warp table keyed on a library word name should become a question to it. The remaining hacks are laws on
operators (rows 7, 9, 13: identities, order, per-type overloads) and declarations that belong to types (rows 15, 17).
